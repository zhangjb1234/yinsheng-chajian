# Fish Audio 语音朗读 for SillyTavern（酒馆）

让酒馆用 [Fish Audio](https://fish.audio/zh-CN/app/discovery/) 的声音朗读角色回复。**纯前端扩展**：不用装服务端插件，不用改 `config.yaml`，不用重启，手机 / 云端酒馆也能用。

- 🔍 **发现音色**：直接在面板里搜索 Fish 声音库，听官方样音，一键添加
- 🎙️ **我的音色**：粘贴链接 / ID 导入，改名、试听、设默认、删除；整套配置可以导出 JSON 发给朋友
- 🎭 **角色绑定**：每个角色一个声音，还可以设旁白声音（台词用角色声音、叙述用旁白声音）
- 📜 **朗读历史**：记录读过的每一条，可重播（走本地缓存，不再消耗额度）、搜索，**一键定位**回原聊天的原楼层；还能**编辑后重新朗读**
- 🎭 **语气标签**（v2.1）：在朗读稿里写 `[开心]` `[whispering]` `[laughing]` `[break]` 这样的 Fish S2 标签，让同一个声音读出不同情绪
  - ✨ **AI 自动加标签**：用酒馆当前的模型、单独的连接配置，或者（v2.2）**单独填一个 OpenAI 兼容接口的地址 + Key + 模型**，朗读前自动插入标签（只加标签、不改原文）
  - 🔒 **不动聊天正文**：标签只存在扩展自己的朗读稿里，聊天记录、角色上下文都不变
  - ✏️ **朗读稿编辑器**：朗读前、或从朗读历史里打开，点按钮插入标签、改字、换音色、删段，改完可以记住，下次朗读同一条自动沿用
- 🎧 **悬浮控制条**：播放 / 暂停 / 跳过 / 停止，可拖动、可收起；每条消息的菜单里也有朗读和编辑按钮
- 🆓 默认用 Fish 官方免费模型 `fish-audio/s2.1-pro-free`

## 安装（二选一，只装一个）

### 方式 A：扩展程序（推荐）

酒馆 → 扩展（积木图标）→ **安装扩展程序** → 粘贴：

```
https://github.com/zhangjb1234/yinsheng-chajian
```

以后在「管理扩展」里就能一键更新。

### 方式 B：酒馆助手脚本

已经装了 [酒馆助手](https://n0vi028.github.io/JS-Slash-Runner-Doc/) 的话：酒馆助手 → 脚本库 → 导入本仓库的 `酒馆助手外壳脚本.json` 并启用。脚本只有一行 `import`，从 jsDelivr 加载本仓库代码；出新版本时把 `@` 后面的版本号改掉即可。

两种方式功能完全一样。如果都装了，只有先加载的那个生效。

## 第一次使用

1. 到 [fish.audio → API 密钥](https://fish.audio/app/api-keys) 创建一个 Key。
2. 酒馆 → 扩展 → 展开 **Fish Audio 语音朗读** → 粘贴 Key → **保存** → 点 **测试朗读**，能听到声音就成功了。
3. 点 **打开语音面板**（或者魔杖菜单里的「Fish 语音面板」、悬浮条上的 ☰）：
   - 「发现音色」里挑声音，点 **添加**
   - 「角色绑定」里点 **添加当前聊天的角色**，给每个角色选声音
4. 开始聊天，新回复会自动朗读。

### Key 存在哪里？

| 模式 | Key 存在哪 | 说明 |
|---|---|---|
| 酒馆密钥库（默认，推荐） | 酒馆的 `secrets.json` | 由酒馆后端转发请求，Key 不会出现在网页里。和酒馆自带 TTS 的「OpenAI Compatible」共用同一个 Key 位 |
| 浏览器直连 | 酒馆扩展设置 | 浏览器直接请求 Fish。只在酒馆版本太旧、没有转发接口时用 |

分享扩展或导出音色配置时，**都不会带上 Key**。

## 朗读设置

- **朗读模式**：整条用角色声音 / 只读引号里的台词 / 分角色 + 旁白。支持 `“”` `""` `「」` `『』`；一条消息里没有引号时会整条朗读。
- **跳过 \*动作描写\***：默认开启。
- **不朗读这些标签**：默认会跳过 `think`、`thinking`、`details`、`StatusBlock`、`status`，可以加上你角色卡状态栏用的标签名。
- **单条最多字数**：默认 800 字，防止长回复刷额度。

## 语气标签（让朗读有情绪）

Fish 的 S2 / S2.1 模型认识写在文字里的**方括号标签**，标签不会被读出来，只会改变说话方式。可以用官方常见标签，也可以直接写英文或中文的自然语言描述：

```
[excited] 真的吗？你要带我去？[laughing] 太好了！
[whispering] 别出声……他好像就在门外。[long-break] [sighing] 算了，走吧。
[用颤抖的声音小声说] 我、我没有哭。
```

- **情绪标签放在句子开头**效果最好；笑声、叹气、停顿放在发生的位置。
- 效果和音色有关：同一个标签在不同音色上的表现差别可能很大，挑一个表现力强的音色效果更明显。
- 选了 **S1** 模型时，扩展会自动把 `[标签]` 换成 S1 用的 `(标签)`；S1 只认官方固定的那一套标签，自然语言描述可能没效果。
- 不想要标签时，在设置里关掉 **把 [语气标签] 发给 Fish**，合成前会去掉所有方括号内容。

### 方法一：AI 自动加

扩展 → Fish Audio 语音朗读 → **语气标签与 AI**：

1. **AI 使用的模型**，三选一：
   - **酒馆当前连接的模型**（默认）：和聊天用同一个 API 和预设。
   - **自定义接口**：单独填一个 OpenAI 兼容接口，只用来加标签，和聊天互不影响。填 **接口地址**（一般以 `/v1` 结尾，例如 `https://api.deepseek.com/v1`、`https://openrouter.ai/api/v1`，本地的 `http://127.0.0.1:5001/v1` 也行）→ 粘贴 **Key** 点 **保存 Key** → 点 **获取模型列表** 选一个模型（或直接手填模型名）。**请求方式** 默认「经酒馆后端转发」，不会遇到浏览器跨域问题；只有接口明确允许跨域时才用「浏览器直连」。
   - **连接配置**：在酒馆「连接配置（Connection Profiles）」里建好的配置。
2. 点 **用试听句测试 AI 加标签**，看到带标签的句子就说明通了，可以点 **朗读结果** 听效果。失败时会显示原因，AI 回复格式不对的话还能展开看 **AI 的原始回复**。
3. 勾上 **朗读前自动让 AI 加语气标签**。之后每条新回复朗读前会先让 AI 加标签（每条会多一次 AI 请求，朗读会晚几秒开始）。

AI 只能插入标签：如果它改了原文的字，那一段会被丢弃、按原文朗读。AI 加好的稿子会记在本浏览器里，重读同一条消息不会再次请求 AI。可以调整 **标签数量**、**AI 提示词**；改坏了点 **恢复默认提示词**。

**会不会改到聊天正文？不会。** 不管是 AI 加的还是手动改的标签，都只存在扩展自己的「朗读稿」里（浏览器 IndexedDB），只在发给 Fish 合成时使用：聊天记录里的消息、角色看到的上下文、导出的聊天文件都不变。加标签的 AI 请求也是单独发的，不会出现在聊天里。

**自定义接口的 Key 存在哪？** 存在本扩展的设置里（酒馆的 `settings.json`），和 Fish「浏览器直连」模式的 Key 一样；导出音色配置时不会带上。Key 留空、又选了「经酒馆后端转发」时，酒馆会用它自己在 API 设置里「自定义（OpenAI 兼容）」保存的 Key。

### 方法二：朗读前手动改

- 每条消息的菜单（`…`）里有 ✏️ **编辑** 按钮：打开朗读稿编辑器，先在文本框里点到要加标签的位置，再点上方的「开心」「小声」「叹气」等按钮插入；也可以输入自定义标签、点 **AI 加标签** 让 AI 先加一遍再手改。
- 改好点 **朗读**；勾着 **记住这条消息的修改** 的话，以后朗读这条消息（包括自动朗读、悬浮条 ▶）都会用改过的稿子。点 **还原原文** 后保存即可取消。
- 想每次都先改再读：把 **朗读前编辑** 设成「点 🎧 时先打开编辑器」，或者「自动朗读的新回复也先打开编辑器」（新回复会弹出编辑器，确认后才朗读）。

### 方法三：从朗读历史里改

语音面板 → **朗读历史** → 某条记录点 **编辑**：改完点 **朗读** 会重新合成并更新这条记录；点 **只保存** 只改记录，下次 **重播** 时才合成。带 `AI 标签` / `已修改` 标记的记录说明用的不是原文。

## 朗读历史和缓存

历史和音频缓存保存在**当前浏览器**的本地存储（IndexedDB）里，不会上传，换设备、换浏览器不会同步，清理网站数据会被删掉。缓存超过上限（默认 80 MB）会自动删除最久没听的音频；被删掉的音频重播时会重新合成。

「定位」会自动打开那条记录所在的聊天并滚动到对应楼层；如果那条消息被删除或者改过，会提示找不到。

## 从旧版（服务端插件）升级

旧版需要把仓库克隆进 `plugins/` 并改 `config.yaml`，新版不需要了：

1. 删除 `SillyTavern/plugins/fish-tts` 文件夹（不想用服务端插件的话，也可以把 `config.yaml` 里的 `enableServerPlugins` 改回去）。
2. 在酒馆助手里停用 / 删除旧的「Fish Audio 语音脚本」。
3. 按上面的方式安装新版。在「我的音色」点 **导入配置**，选择旧的 `voices.json`，音色会自动导入；然后到「角色绑定」重新绑定角色。

> 旧版的「即时克隆」（`ref:素材文件夹`）新版不支持。替代办法：在 fish.audio 网站用同一份素材创建一个音色，再把音色链接粘贴到「我的音色」。

## 常见问题

- **悬浮条不见了**：扩展 → Fish Audio 语音朗读 → 点 **找不到悬浮条？重置位置**，它会回到右下角。也可以从魔杖菜单的「Fish 语音面板」打开面板。
- **卸载后重新安装，扩展完全没反应（扩展页里连设置抽屉都没有）**：如果卸载前在「管理扩展」里关掉过它，酒馆会一直记着“已停用”，重装也不会清掉。打开「管理扩展」，把 Fish Audio 语音朗读的开关打开，关闭窗口后页面会刷新。
- **扩展和酒馆助手外壳脚本只装一个**：两个都开着时只有先加载的那个生效。
- **手机上第一条不出声**：浏览器禁止网页自动播放声音。点一下悬浮条上的 ▶，之后就能正常自动朗读。
- **提示「API Key 无效」**：重新保存 Key；用「酒馆密钥库」模式时，确认没在酒馆自带 TTS 里把同一个 Key 位换成了别家的 Key。
- **提示「当前酒馆版本没有 OpenAI 兼容 TTS 转发接口」**：升级酒馆，或者在设置里改用「浏览器直连」。
- **提示余额 / 额度不足**：免费模型遵循 Fish 的公平使用政策；可以换成计费模型并在 fish.audio 充值。
- **加了标签听不出区别**：换一个表现力强的音色试试；把情绪标签挪到句子开头；或者写得更具体，比如 `[带着哭腔小声说]`。
- **标签被读出来了**：确认模型是 S2 / S2.1（S1 只认固定标签），并且标签用的是英文方括号 `[ ]`，不是中文的【】。
- **AI 加标签失败 / 总说“改动了原文”**：有的模型会顺手润色、翻译或拒绝露骨内容。最省事的办法是把「AI 使用的模型」改成 **自定义接口**，填一个听话、限制少的模型；也可以把标签数量调成「少量」，或者在提示词里再强调一次“不要改字”。点「用试听句测试」能看到具体原因和 AI 的原始回复。AI 失败时这条会按原文朗读，不会卡住。
- **自定义接口提示「接口地址或模型名不对」**：地址填到 `/v1` 为止，不要带 `/chat/completions`（带了也会自动去掉）；模型名用「获取模型列表」选。
- **自定义接口提示「浏览器直连失败」**：这个接口不允许网页跨域，把「请求方式」改回「经酒馆后端转发」。
- **自定义接口提示「AI 只输出了思考过程」**：推理模型把 token 用在思考上了，把「AI 最多回复 token 数」调大（比如 4000），或换一个非推理模型。
- **改了朗读模式后，之前保存的修改不见了**：保存的稿子是按「这条消息在当前设置下拆出来的原稿」记的，换朗读模式、跳过规则或字数上限后原稿变了，就会当成新的一条。
- **换浏览器后修改不见了**：朗读稿和历史一样只存在当前浏览器里。
